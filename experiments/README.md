# Эксперименты

Каждый запуск пишет компактный отчёт в `experiments/<run_id>/` и большие файлы
(`oof.csv`, `submission.csv`, модели) в `artifacts/<run_id>/`. После запуска
проверяем метрики и коммитим отчёт отдельным коммитом.

Сравниваем эксперименты по **общему OOF ROC AUC** на одинаковых пяти фолдах.
Среднее и стандартное отклонение ROC AUC по фолдам тоже сохраняем, чтобы видеть
стабильность. Для теста усредняем **вероятности** пяти моделей, обученных на
разных тренировочных частях фолдов. Максимум по фолдам не используем.

Порядок работы:

1. Базовый LightGBM на исходных признаках.
2. Подбор гиперпараметров с теми же фолдами.
3. Анализ важности исходных признаков.
4. Новые признаки: одно изменение и один эксперимент на коммит.
